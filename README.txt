# Greg Mom Portfolio

## Folder structure

- `index.html` — main website
- `styles.css` — design and responsive layout
- `script.js` — animations, gallery lightbox, filters, dark mode, contact form
- `images/` — sample gallery images

## Add your own photos

1. Put your photos inside `images/`.
2. Open `index.html`.
3. Find the `gallery-grid` section.
4. Replace a sample filename such as `images/university.svg` with your own file, for example `images/my-campus-photo.jpg`.
5. Change the `alt`, title, and caption if desired.

## Resume

When you have your final resume PDF, put it in this folder as `Greg-Mom-Resume.pdf`, then add a link such as:

<a href="Greg-Mom-Resume.pdf" target="_blank">View Resume</a>

## Publish online

This is a static HTML/CSS/JavaScript site and is suitable for GitHub Pages. GitHub Pages publishes static files from a repository and uses `index.html` as an entry file.
